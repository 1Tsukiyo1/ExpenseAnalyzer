# Анализатор расходов

Консольное приложение на C# для просмотра, добавления и отбора расходов, а также формирования отчётов. Вычислительная логика находится в библиотеке `ExpenseAnalytics.Core`, а консольное взаимодействие - в `ExpenseAnalytics.ConsoleApp`.

При запуске загружаются восемь начальных расходов за октябрь 2026 года. Добавленные записи хранятся в памяти до завершения программы.

## Требования

- .NET SDK 6.0 или новее.
- Решение содержит проекты `ExpenseAnalytics.Core` и `ExpenseAnalytics.ConsoleApp`.
- `ExpenseAnalytics.ConsoleApp` ссылается на `ExpenseAnalytics.Core`.

## Команды меню

- `1` — показать все расходы.
- `2` — добавить расход.
- `3` — отобрать расходы по необязательным критериям.
- `4` — сформировать отчёт по выбранным расходам.
- `0` — завершить работу.

Даты вводятся в формате `дд.мм.гггг`, например `10.10.2026`. В формах критериев пустой ввод означает, что критерий не задан.

## Структура

```text
ExpenseAnalytics.Core/
    ExpenseAnalytics.cs
ExpenseAnalytics.ConsoleApp/
    Program.cs

README.md
```

Данные приложения не сохраняются в файл. После завершения и повторного запуска снова загружается начальный список.
